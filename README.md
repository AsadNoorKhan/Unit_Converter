# Unit Converter 🔄

A web-based unit converter built with **Streamlit**, allowing users to convert various units (length, weight, temperature, etc.) and currency values between different currencies.

## 🚀 Features

- **Unit Conversion**:
  - Supports conversion for various categories such as length, weight, temperature, speed, volume, area, and data size.
  
- **Currency Conversion**:
  - Real-time conversion of currency values using an external API (ExchangeRate-API).

- **Interactive UI**:
  - Built with **Streamlit** for easy interaction and instant feedback.

- **History Tracking**:
  - Conversion history is stored and can be cleared by the user.
